1.Personal Portfolio Website

 2.About the Project
This is my personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my profile, technical skills, projects, educational background, and contact information.

The website is designed with a modern dark blue and teal theme and provides a responsive layout for desktop and mobile devices.

3. Features
- Home section with personal introduction.
- About Me section.
- Technical Skills section.
- Projects showcase.
- Education details.
- Contact section with an email preparation form.
- Responsive navigation menu.
- Print / Save as PDF functionality.
- Smooth scrolling.
- Dynamic copyright year.

 4.Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Interactive functionality and navigation.
  
 5.Project Structure

 6. How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `portfolio.html`.
4. Right-click and select **Open with Live Server**.
5. View the portfolio in your browser.

You can also open `portfolio.html` directly in your browser.
